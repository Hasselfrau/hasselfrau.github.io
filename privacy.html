Privacy policy

couplebot-backup is a private tool used only by its owner to upload encrypted backup files to the owner's own Google Drive.

What it accesses

It requests only the drive.file permission, so it can see and change only the files it created itself. It cannot read any other files in the Google Drive.

What it does with data

Backups are encrypted before upload. No data is sold, shared with third parties, or used for advertising or analytics. Google user data is used only to store and retrieve these backups.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
